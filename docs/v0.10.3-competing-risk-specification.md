# ITRF v0.10.3 Competing-Risk Calibration Specification

## Purpose

Version 0.10.3 tests whether causal trade-path state improves next-bar stop and
target hazard calibration beyond empirical holding-bar hazards and pre-entry
features. It is a probability-framework test, not a strategy, exit-model
comparison, or profitability claim.

This specification is frozen before historical model results are inspected.
No probability may be converted into a stop movement, partial exit, target,
entry filter, or position-size rule.

## Risk-set rows and causal clock

Each unambiguous v0.10 accepted event contributes one row for every bar on
which it is at risk. A row predicts the mutually exclusive event occurring
during that bar:

- `STOP`
- `TARGET`
- `NONE` (neither bracket event; includes the bar-32 timeout close)

Features for holding bar *k* are limited to signal-time information and path
information completed through bar *k - 1*. Current-bar OHLC values never enter
the current-bar prediction. Bar 1 path-state values are fixed to zero.

## Fixed feature families

### Time and pre-entry model

- known holding fraction `(holding_bar - 1) / 32`
- fixed lifecycle phase indicators for bars 1-4, 5-16, 17-31, and 32
- direction
- v0.8 trend alignment
- direction-signed momentum/ATR
- direction-signed delta-proxy z-score
- relative tick activity
- v0.8 high-volatility flag

### Dynamic path-state model

The pre-entry model plus values known at the prior completed bar:

- running MFE in R
- running MAE in R
- prior close relative to entry in directional R
- prior bar range in R
- prior close-to-close change in directional R

No same-bar terminal extreme is used as a predictor.

## Fixed benchmarks and models

1. `empirical_hazard`: exact holding-bar STOP/TARGET/NONE frequencies in the
   training fold with fixed Jeffreys smoothing of 0.5 per category
2. `preentry_time`: deterministic multinomial logistic regression
3. `dynamic_path`: the same regression with the fixed prior-path state

Both regressions use training-only median imputation and standardization,
unpenalized intercepts, fixed L2 strength 1.0, and no hyperparameter search.

## Chronological evaluation

- Event-level split: the same three expanding v0.10.1 walk-forward folds
- Initial test begins after 40% of chronological events
- 32-source-bar pre-test embargo
- Training events must terminate before the embargo boundary
- All rows from one event remain in the same fold
- Preprocessing and empirical hazards use training rows only
- Ambiguous events are excluded from fitting and scoring

## Metrics

- Multiclass Brier score across STOP/TARGET/NONE
- Event-balanced multiclass Brier score (each event receives equal weight)
- Multiclass log loss
- Mean predicted and observed cause frequency
- Paired circular block-bootstrap 95% interval for event-balanced Brier
  improvement versus `empirical_hazard`

Positive improvement is defined as lower Brier error than the benchmark.
Because rows within an event are dependent, uncertainty is calculated after
averaging row errors within each event.

## Decision rule

This inspected sample can only show whether dynamic path state is calibrated
well enough to justify a future frozen validation. It cannot promote a trading
action. A visually attractive fold, cause, direction, or holding bar may not be
selected after results.
