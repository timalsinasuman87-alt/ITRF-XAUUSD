# ITRF v0.10.4 External-Transport Specification

## Purpose

Version 0.10.4 tests whether the frozen v0.10.3 competing-risk models transport
to a longer, previously unused segment of the same historical XAU/USD feed.
It is an external calibration test, not a parameter search, strategy
optimization, profitability test, or management-policy experiment.

The external segment predates the development segment.  This is therefore a
**backward temporal transport test**, not the required future chronological
holdout.  It can reject fragile calibration, but it cannot replace validation
on data collected after 2026-08-07.

This specification is frozen before any signals, event outcomes, model
predictions, or performance metrics are calculated on the external segment.

## Locked data

- Instrument: historical XAU/USD only
- Bar interval: 15 minutes
- Source type: HistData midpoint bars; volume is tick count
- Full local file: `data/XAUUSD_2025_2026.csv`
- Full-file SHA-256:
  `014b6e90ca0e5731b2fd3b958adb7c772d2adf974cf96e9d6cd424964779d058`
- External interval: 2025-01-01 18:00:00 through 2026-04-30 23:45:00
- External rows before feature warm-up: 31,330
- Development interval: 2026-05-01 00:00:00 through
  2026-08-07 16:45:00
- Development rows: 6,466
- The development interval is an exact OHLCV subset of the full local file.

The external interval must not be changed, shortened, sliced by result, or
replaced after evaluation.  No additional data is downloaded for this test.

## Frozen event and path definitions

- Frozen v0.8 entry detection and feature definitions
- Frozen v0.10 one-position candidate sequencing
- Entry at the next bar open
- Initial risk: 1.5 ATR
- Fixed target: 3R
- Maximum holding period: 32 bars
- Same-bar stop/target ambiguity excluded from fitting and scoring
- One causal risk-set row for every at-risk holding bar
- Each row predicts `NONE`, `STOP`, or `TARGET` during that bar
- Path features use only information completed through the prior bar
- Bar-1 path-state features remain zero

The first 250 bars of each segment are warm-up history.  No event may cross the
boundary between the external and development segments.

## Frozen training and transport procedure

1. Build the development and external event ledgers independently.
2. Build their lifecycle panels and causal risk-set rows independently.
3. Fit all preprocessing and models on development risk rows only.
4. Apply the fitted objects unchanged to every eligible external risk row.
5. Do not refit, recalibrate, tune, select, or inspect a subgroup on external
   outcomes.

The three unchanged v0.10.3 models are:

1. `empirical_hazard`: exact holding-bar cause frequencies with Jeffreys
   smoothing of 0.5 per class
2. `preentry_time`: fixed L2 multinomial model using the v0.10.3 time and
   pre-entry features
3. `dynamic_path`: the same model plus the five frozen prior-bar path features

Both regressions retain L2 strength 1.0 and development-only median imputation
and standardization.

## Locked metrics

- Multiclass Brier score
- Event-balanced multiclass Brier score
- Multiclass log loss
- Mean predicted and observed stop frequency
- Mean predicted and observed target frequency
- Event-balanced Brier improvement versus `empirical_hazard`
- Paired circular block-bootstrap 95% interval for that improvement

The event is the unit of uncertainty.  A positive improvement means lower
event-balanced Brier error than the empirical holding-bar benchmark.

## Decision rule

The dynamic prior-path model passes this transport test only if all of the
following hold on the complete locked external sample:

1. event-balanced Brier improvement versus `empirical_hazard` is positive;
2. the paired 95% bootstrap interval has a lower bound above zero;
3. dynamic-path log loss is lower than empirical-hazard log loss; and
4. no integrity or causality check fails.

Failure on any condition rejects transport stability.  Results may not be
rescued by choosing a direction, year, phase, probability range, or outcome
after inspection.

Even a pass only supports continued probability research.  It does not
validate profitability, create a stop adjustment, partial exit, trailing rule,
entry filter, position size, alert, or live-trading instruction.  Future
chronological validation after 2026-08-07 remains mandatory.

## Cost and safety
