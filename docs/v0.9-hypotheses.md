# ITRF v0.9 contextual framework (research-only)

## Scope and baseline protection

The validated v0.8 engine remains unchanged: `detect_setup`, forward outcome
labelling, SQLite schema, and OOS reports retain their existing definitions.
Version 0.9 adds a separate, causal context layer in `research/itrf_context.py`.
It is not included in v0.8 reports and has not been optimized against outcomes.
`research/run_v09_research.py` writes its observations to a separate v0.9
database and retains v0.8's frozen OOS boundary for descriptive reporting.

## Frozen definitions

| Component | Definition |
| --- | --- |
| Regime | `TREND_UP` when EMA 50 > EMA 200, `TREND_DOWN` when below, otherwise `RANGE`; volatility is ATR/close versus its rolling 100-bar median. |
| Structure | A swing needs three bars on both sides. It becomes known three bars after the pivot. A close beyond the last known swing is BOS; an opposite-direction BOS while the prior structure bias was opposite is CHoCH. |
| Liquidity | External high/low are the maximum/minimum of the preceding 20 completed bars. A buy-side/sell-side sweep takes that level and closes back through it. |
| Location | Premium/discount is close above/below the midpoint of the latest confirmed swing high and low. |
| Entry confirmation | Long: sell-side sweep + discount + bullish BOS/CHoCH + bullish displacement. Short is symmetric. Displacement requires body ratio >= 0.60 and range/ATR >= 1.00. |
| Risk sizing | Candidate risk is 0.5% of equity. Stop is beyond the signal low/high and relevant confirmed swing, plus 0.10 ATR. Units are risk budget divided by price risk, before broker contract multiplier/costs. |

## Trade management hypothesis

The v0.9 trade-management study compares four fixed rules against the same v0.8
entry candidates: fixed 3R target; 50% realized at 2R then a 1-ATR trailing
stop; break-even stop activated after 1R; and a 1-ATR trailing stop. Initial
risk is the existing v0.8 1R distance (1.5 ATR). The trail uses the best
completed-bar high/low and takes effect on the following bar.

These conventions are pre-registered starting definitions, not tuned values.
The fixed 32-bar horizon is retained. Max drawdown is reported in R on a
sequential-signal curve, so it does not represent an executable portfolio with
one position at a time; a candidate is skipped while that model has an open
trade. A future held-out study must use broker-specific spread, commission,
slippage and contract-multiplier inputs. It must not select a winner using the
same data used to formulate the rules.

## Running the study

After adding real OHLCV data to `data/XAUUSD.csv`, run:

```bash
python research/run_v09_research.py
```

The output has an all-history descriptive table and a table from the frozen v0.8
OOS boundary forward. Neither table is a basis for choosing or tuning a rule.

To run the exit-model comparison on the v0.8 entry set:

```bash
python research/run_v09_trade_management.py
```

The runner accepts explicit broker assumptions, all defaulting to zero so no
values are invented: `--spread-price`, `--slippage-price-per-side`,
`--commission-per-contract-per-side`, and `--contract-multiplier`. It stores a
trade log (entry/exit timestamps and prices, gross R, cost R, net R, exit reason
and holding bars) in `database/itrf_v09_trade_management.db` and reports
in-sample versus frozen-OOS results separately.

## TradingView diagnostic cohorts

The TradingView research strategy exposes descriptive cohorts: long/short,
with-trend/countertrend under EMA 50/200, and high/low ATR-percent volatility.
Use the same date range, exit model, costs and timeframe for every cohort. These
are diagnosis views, not a search for the best filter; any later rule change
must be pre-declared and tested on a separate unseen period.

The following descriptive results were recorded manually in TradingView on the

## Pine parity

`tradingview/ITRF_XAUUSD_v09_reference.pine` implements the overlapping chart
definitions: EMA regime, ATR volatility label, confirmed pivots, BOS/CHoCH,
external-liquidity sweeps, premium/discount, displacement and confirmation.
It now also contains the frozen v0.9.1 eight-bar causal state machine. Structure
events require the first close-cross of a confirmed swing; staying beyond the
same swing does not emit repeated BOS events.
`tradingview/ITRF_XAUUSD_v09_research_strategy.pine` translates the v0.8 entry
score and all four fixed v0.9 exit models for chart-level comparison. The Python
module remains the source of truth for research and position sizing. TradingView
can simulate intra-bar order fills differently from the Python study; configure
costs in Strategy Properties and treat mismatches as evidence to investigate,
not values to tune.

## Local data-source checkpoint

On 2026-08-16, the research engine was run on locally imported HistData XAU/USD
tick archives for 2026-05-01 through 2026-08-07. Midpoint OHLC bars were built
from bid/ask ticks and the number of ticks per 15-minute bar was used only as an
activity proxy; it is not broker volume or a TradingView-equivalent data feed.

Using the same chronological 2026-06-20 split, the engine produced 199 earlier
observations and 185 later observations. The later-period v0.8 baseline average
was -0.200R (long: -0.187R; short: -0.213R). This does not support a general
v0.8 edge in this independent source check. It also does not invalidate the
separate TradingView long/EMA-uptrend hypothesis, because the data feed,
activity proxy, and engine outcome simulation differ. No parameters or trading
rules were changed from this checkpoint.

The engine now requires an OOS boundary inside the available data range. It
skips OOS reports rather than mislabeling an entire dataset when the requested
date is unavailable. Supply a valid boundary with `--oos-start` for a
chronological local check.

## Limitations

- OHLCV cannot establish true bid/ask order flow or institutional intent.
- A bar can cross a stop and target in an unknown intrabar order; v0.8 retains
  its conservative forward-outcome handling.
- These are testable labels, not evidence of profitability or investment advice.
