# ITRF v0.10.3 Competing-Risk Calibration Results

## Status

The pre-registered v0.10.3 next-bar competing-risk comparison has been
completed on the already inspected XAU/USD development sample. It evaluates a
probability framework; it does not test profitability or authorize a trade
management action.

The causal risk rows, fixed feature families, models, folds, metrics, and
decision rule were committed before valid historical model output was
inspected. No new data was downloaded, no live feed or order path was used, and
the incremental cost was $0.

## Causality and conservation

- Complete risk-set rows: 2,601 across 212 accepted events
- Walk-forward test rows: 1,594 across 128 events

| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| Empirical holding-bar hazard | 0.13513 | 0.42507 | 0.29931 | 6.732% | 5.960% | 2.381% | 1.066% |

Dynamic prior-path state lowered pooled row Brier error and log loss and was
closest to the observed stop frequency. It still overpredicted the rarer target
event, and pooled improvement alone is not sufficient evidence.

## Event-balanced uncertainty

| Model versus empirical hazard | Mean Brier improvement | Circular block-bootstrap 95% interval |
| --- | ---: | ---: |
| Pre-entry and time | -0.00469 | [-0.01138, 0.00295] |
| Dynamic prior-path state | +0.00544 | [-0.01689, 0.02571] |

Positive values mean lower event-balanced Brier error. The dynamic mean is
positive, but its interval crosses zero widely. The inspected sample therefore
does not establish stable incremental calibration.

## Fold stability

| Fold | Empirical event-balanced Brier | Dynamic event-balanced Brier | Dynamic improvement |
| --- | ---: | ---: | ---: |
| 1 | 0.40463 | 0.40940 | -0.00477 |
| 2 | 0.43923 | 0.44088 | -0.00166 |
| 3 | 0.43151 | 0.40834 | +0.02316 |

The dynamic model improved event-balanced error only in the newest fold. It
did lower log loss in all three folds, but selecting log loss, fold 3, or a
high-confidence path state after seeing these results would violate the
pre-registered decision rule.

## Numerical integrity correction

The first historical execution stopped before producing model results because
the deterministic optimizer did not meet its convergence tolerance. That run
was invalid. The numerical step bound was tightened using deterministic power
iteration with a global softmax curvature bound; labels, features, folds,
regularization, and metrics were unchanged. The dedicated and full test suites
then passed under warning-sensitive execution before the report above was
accepted.

## Decision

Prior completed-bar path state contains a **promising but unvalidated**
calibration signal. It materially improves pooled log loss, yet event-balanced
improvement is unstable across folds and statistically inconclusive. No
probability cutoff, break-even rule, partial exit, trailing stop, or position
adjustment is promoted.

## Next research requirement

Do not tune this model on the inspected sample. The correct next evidence is a
new untouched chronological XAU/USD period with the entire v0.10.3 pipeline
frozen. Validation must retain the same features, L2 strength, empirical
benchmark, embargo, and metrics. Only stable calibration on new data could
justify pre-registering a separate management-policy experiment.
