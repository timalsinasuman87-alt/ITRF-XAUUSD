# ITRF v0.10.4 External-Transport Results

## Status

The pre-registered v0.10.4 backward external-transport test has been completed
on the locked, previously unused XAU/USD segment from 2025-01-01 18:00 through
2026-04-30 23:45.  The frozen v0.10.3 models were fitted only on the separate
May-August 2026 development segment and transported unchanged.

This is a calibration result, not a profitability result.  Because the
external period predates model development, it is a backward temporal
transport test and does not replace the future holdout beginning after
2026-08-07.

No data was downloaded, no live feed or broker connection was used, no order
was placed, and the incremental cost was $0.

## Locked sample and integrity

- Full local file SHA-256 matched the pre-registered value
- Development bars: 6,466
- External bars before warm-up: 31,330
- Eligible development events: 212
- Eligible external events: 1,046
- Development risk rows: 2,601
- External risk rows: 13,554
- Prediction rows: 40,662 (13,554 for each of three models)
- Duplicate model/event/holding-bar predictions: 0
- Maximum probability-sum error: 5.55e-16
- All 1,046 first-holding-bar prior-path feature vectors were exactly zero
- External outcomes were not used in model fitting or preprocessing

The first 250 bars were used only as feature warm-up within each independently
built segment.  No event crossed the external/development boundary.

Positive values mean lower event-balanced Brier error.  The pre-entry model
failed to transport against the empirical benchmark.  The dynamic path model
improved event-balanced Brier error with its full confidence interval above
zero and also lowered log loss.

## Pre-registered decision

The dynamic prior-path model **passes** the v0.10.4 backward external-transport
rule:

1. mean event-balanced Brier improvement was positive;
2. the paired bootstrap interval lower bound was above zero;
3. external log loss was lower than the empirical benchmark; and
4. all integrity and causality checks passed.

This supports the narrow conclusion that completed prior-bar path state carries
transportable information about next-bar stop/target risk on this historical
XAU/USD feed.  It does not show that acting on those probabilities improves
returns after costs, and it does not validate a profitable strategy.

## Research decision and next increment

Do not tune v0.10.3 from these results.  Do not choose a probability cutoff or
management action after inspecting this sample.

The evidence is now sufficient to justify a separate, pre-registered v0.10.5
management-policy experiment.  That experiment must define one economically
motivated use of the frozen probability state before evaluating outcomes,
retain a no-action benchmark, use realistic XAU/USD execution costs, and keep
the future post-2026-08-07 holdout untouched.  Passing this backward transport
test does not waive that future validation requirement.
